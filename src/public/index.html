API Endpoints Documentation

Console Endpoints

  • GET /consoles

    Retrieves a list of all consoles with optional limit, offset, and sort order.

    Query Parameters: ?limit=10&offset=0&sort=desc

    Sort Order:

    • asc for ascending order (e.g., alphabetical or numerical from low to high)
    • desc for descending order (e.g., alphabetical or numerical from high to low)

    Response: 200 OK with list of consoles.

  • GET /consoles/:id

    Retrieve details of a specific console by ID.

    Response: 200 OK with console details or 404 Not Found if not found.

  • POST /consoles

    Create a new console.

    Request Body: 

    {
                        "name": "PlayStation",
                        "manufacturer": "Sony",
                        "release_year": 1994
                    }

    Response: 201 Created with the created console.

  • PUT /consoles/:id

    Update an existing console.

    Request Body: 

    {
                        "name": "PlayStation 5",
                        "manufacturer": "Sony",
                        "release_year": 2020
                    }

    Response: 200 OK with updated console or 404 Not Found if not found.

  • DELETE /consoles/:id

    Delete a console by ID.

    Response: 204 No Content if successfully deleted, or 404 Not Found if not found.

Game Endpoints

  • GET /games

    Retrieve a list of all games with optional limit, offset, sort order, and search parameters.

    Query Parameters: ?limit=10&offset=0&sort=desc

    Sort Order:

    • asc for ascending order (e.g., alphabetical or numerical from low to high)
    • desc for descending order (e.g., alphabetical or numerical from high to low)

    Response: 200 OK with list of games.

  • GET /games/:id

    Retrieve details of a specific game by ID.

    Response: 200 OK with game details or 404 Not Found if not found.

  • POST /games

    Create a new game.

    Request Body: 

    {
                        "title": "The Last of Us",
                        "genre": "Action",
                        "release_year": 2013,
                        "console_id": 1
                    }

    Response: 201 Created with the created game.

  • PUT /games/:id

    Update an existing game.

    Request Body: 

    {
                        "title": "The Last of Us Part II",
                        "genre": "Action",
                        "release_year": 2020,
                        "console_id": 1
                    }

    Response: 200 OK with updated game or 404 Not Found if not found.

  • DELETE /games/:id

    Delete a game by ID.

    Response: 204 No Content if successfully deleted, or 404 Not Found if not found.

  • GET /games/search

    Search games by title and/or genre.

    Query Parameters: ?title=Last&genre=Action

    Response: 200 OK with filtered games list.
