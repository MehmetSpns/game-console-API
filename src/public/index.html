API Documentation

Games

  • GET /api/games - List all games
  • GET /api/games/:id - Get a specific game
  • POST /api/games - Create a new game
  • PUT /api/games/:id - Update an existing game
  • DELETE /api/games/:id - Delete a game
  • GET /api/games/search - Search games by title or genre

Consoles

  • GET /api/consoles - List all consoles
  • GET /api/consoles/:id - Get a specific console
  • POST /api/consoles - Create a new console
  • PUT /api/consoles/:id - Update an existing console
  • DELETE /api/consoles/:id - Delete a console
